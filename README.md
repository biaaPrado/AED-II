# AED2 - Algoritmos e Estruturas de Dados 2
 
Repositório dedicado à disciplina de Algoritmos e Estruturas de Dados 2, reunindo exercícios, implementações e trabalhos desenvolvidos ao longo do curso.
 
## 📋 Conteúdo
 
O repositório inclui implementações de:
 
- **Algoritmos de ordenação** (ex: bubble sort, insertion sort, merge sort, quick sort, heap sort)
- **Algoritmos de busca** (busca sequencial, busca binária)
- **Grafos**: representação (matriz de adjacência / lista de adjacência), percursos (BFS, DFS) e algoritmos clássicos
- **Árvores balanceadas**:
  - Árvore AVL
  - Árvore Rubro-Negra (Red-Black Tree)
  - Árvore B
- **Tabela Hash** 
## 🛠️ Tecnologias utilizadas
 
- **Linguagem:** C
## 📁 Organização
 
Os arquivos estão organizados por tópico/atividade, contendo o código-fonte das implementações e, quando aplicável, arquivos de teste para validação dos algoritmos e estruturas.
